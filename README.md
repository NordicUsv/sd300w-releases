# SD300W – nedlastinger

Ferdige versjoner av SD300W, Nordic USV sitt interne verktøy for SAIV CTD-instrumenter.
Filene her lages automatisk; koden ligger i et privat repo.

Siste versjon: 0.1.34

- Windows: [SD300W_0.1.34_x64-setup.exe](https://raw.githubusercontent.com/NordicUsv/sd300w-releases/main/windows/SD300W_0.1.34_x64-setup.exe)
- Mac (Apple Silicon): [SD300W_0.1.34_aarch64.dmg](https://raw.githubusercontent.com/NordicUsv/sd300w-releases/main/macos/SD300W_0.1.34_aarch64.dmg)

Installer én gang med lenkene over. Etter det sier SD300W selv fra når det finnes en ny versjon.

- Windows sier «Windows beskyttet PC-en»: velg «Mer info» → «Kjør likevel».
- Mac sier at appen ikke kan åpnes: dra SD300W til Programmer, åpne den én gang, gå til
  Systeminnstillinger → Personvern og sikkerhet og velg «Åpne likevel».
