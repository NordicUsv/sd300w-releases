# SD300W – nedlastinger

Ferdige Windows-versjoner av SD300W, Nordic USV sitt interne verktøy for SAIV CTD-instrumenter.
Filene her lages automatisk; koden ligger i et privat repo.

Siste versjon: [0.1.2](https://raw.githubusercontent.com/NordicUsv/sd300w-releases/main/windows/SD300W_0.1.2_x64-setup.exe)

Installer én gang med lenken over (Windows sier «Windows beskyttet PC-en», velg «Mer info» → «Kjør likevel»).
Etter det sier SD300W selv fra når det finnes en ny versjon.
